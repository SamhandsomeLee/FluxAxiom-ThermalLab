## Not Verified

- 本机没有 `linux-asan` 的本地日志。Linux 作业的成功结论来自 `d73b833` 的 GitHub Actions。
- OpenVINO GPU 与 OpenCL 没有运行过。
- P2 Pro 未到手。ESP32 只记录了型号 DNESP32S3M，蜂鸣器、LED、光敏元件未确认。没有可见光 UVC 摄像头。
- 硬件视频编码器没有在 Orin Nano 板上确认。
- 睿创微纳红外开源平台只读了超分数据库的版权声明。训练得到的模型权重没有被该声明授权公开发布。
- CUDA EULA 只读了页首。Qt Charts 没有单独打开页面。
- `c2a0837` 及其后尚未推送的提交没有 CI 运行记录。

## 本阶段可声明的范围

可以声明的是：仓库里有一个导出 `tl_get_version` 的 C 动态库，Windows 与 Linux 的 CI 曾在 `d73b833` 上四个作业成功，并且失败的必选检查挡过一次合并。许可证表有一轮带日期和 URL 的核对。

不能声明的是：Jetson 上运行过交叉编译产物、SDK 已能测温、QA-01 的集成与性能报告已经完成、G0 整阶段通过。BUILD-01 只在 `d73b833` 的那次运行上有作业结论。
